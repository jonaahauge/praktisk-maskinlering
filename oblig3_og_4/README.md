# Kort beskrivelse av mappe struktur for oblig 3 og 4.

For å strukturen og filene disse obligene mer oversiktig har jeg valgt å splitte opp filene i forkjellige mapper/kategorier.

- Utforskende analyse av datasettene, "data_analye"
- Trening, tuning og analyse av supervised modelene, "supervised_learing"
- Trening,tuning og analyse av neural network modellene, "neural_network"
- Sammenligning mellom supervised og neural network modellene, "supervised_vs_neural"
